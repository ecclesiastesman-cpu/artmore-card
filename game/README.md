# ПОСЛЕДНЯЯ СВЕЧА (Last Candle)

Мрачная оффлайн ARPG в духе Diablo. HTML5/Canvas, PWA — работает без интернета.

**Играть:** https://lush-quartz-123.higgsfield.gg/

## Как поставить на iPhone (для полёта)
1. Открой ссылку в **Safari** (с интернетом, один раз).
2. Кнопка «Поделиться» → **«На экран "Домой"»**.
3. Запусти с иконки, дождись титульного экрана — игра скачана.
4. В самолёте открывай с иконки: всё работает оффлайн, сохранения на телефоне.

## Что внутри
- 5 классов: Варвар, Охотница, Маг, Чернокнижник, Друид (формы волка и медведя)
- 3 ветки талантов на класс, ~20 умений, ранги, респек
- Лут: 10 слотов, аффиксы, редкие/уникальные/сетовые вещи, видимая экипировка на герое
- 4 акта с боссами, процедурные этажи, элитные монстры, бесконечные Порталы
- Скупщик, сундук, гэмбл; автосохранение (localStorage)
- Управление: тач (джойстик + кнопки), клавиатура (WASD/стрелки, Space/J, K/L/U/I, Q, Tab), геймпад

## Структура
- `index.html`, `src/` — движок (ES-модули, фикс. таймстеп, сид-RNG)
- `assets/` — обработанные ассеты (webp), `assets_raw/` — сырьё генераций
- `design/` — дизайн-док, манифест ассетов, журнал генераций
- `tools/` — обработка ассетов, плейсхолдеры, чек-лист проверки
- `sw.js`, `manifest.webmanifest` — PWA-оффлайн
- `deploy/` — пакет и данные публикации (game_id для обновлений!)

## Обновление ассетов (когда появятся кредиты Higgsfield)
Рабочий промпт изоляции проверен (см. `assets_raw/test_ghoul.png`):
«isolated game character asset: one single <описание>, full body, centered, completely alone on a flat solid uniform bright magenta pink background like a sticker cutout, absolutely no scenery... + стилевой токен» — z_image, 0.15 кр/шт.
Перегенерировать ~30 спрайтов ≈ 5–7 кредитов, затем: мост fetch-assets → tools/process_assets.py → пересборка зипа → deploy_game с тем же game_id.
